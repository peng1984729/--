### 模型预训练：

通过大量数据预先训练出一个通用神经网络，它学习了大量通用的特征。

浅层学习了**边缘、颜色、纹理**等低级特征；深层学习了物体**部位、种类、风格**等高级特征。

#### 微调：

调用预先训练好的神经网络，使用更小的训练集进行**二次训练**。

在训练过程中提取训练集特征，对预训练的模型参数经行**微小调整**。

#### **好处：**

| 好处                   | 说明                                               |
| ---------------------- | -------------------------------------------------- |
| 节省计算资源与时间     | 无需从随机初始化开始，跳过基础特征提取，训练更快。 |
| 小数据集也能训练好模型 | 缓解数据不足导致的过拟合，提高拟合准确率。         |
| 迁移学习能力           | 通用特征可迁移到不同任务（分类、检测、分割等）     |
| 拟合效果更优秀         | 随机初始化容易陷入较差局部最优                     |

### 冻结参数：

固定预训练模型中的一些层的权重，即计算梯度反向传播时**不再更新**。

一般冻结卷积层（保留模型的特征提取器）。

#### 作用：

**防止过拟合**：

数据集小时，全部参数参与更新，模型容易记住训练集噪声。

**提高训练效率，减小计算量**：

需要计算梯度、更新的参数减少。

**保留通用特征**：

增强模型的拟合能力。

#### 超参数设置：

学习率大幅度减小，通常用**1e-4 ~ 1e-5**。

学习率分层设置，深层学习率较大，浅层学习率极低甚至0（直接冻结）。

训练轮数适当减少，提高训练效率。

### 风格迁移：

风格迁移中需提取A图特征，B图风格。

提取**内容**：预训练模型可以高效提取A图与生成图的特征值（一般卷积层），以此快速计算差异，即为特征的loss。

提取**风格**：对多层特征图计算Gram矩阵，其可以提取纹理、笔触、颜色分布等风格特征，与空间位置无关。Gram矩阵之差就是风格的loss。

### VGG16

VGG16通过13个卷积层与3个全连接层对图像的特征与风格进行提取。

![](https://i-blog.csdnimg.cn/blog_migrate/47255b5a5c921ab82bc796887e2f875f.png)

如图VGG16分为6部分，前5部分为**卷积+池化+激活函数**，最后1部分为**全连接**。

#### **卷积**：

通过增加**小卷积核数量**来增加图像**通道数**。

同一通道，进过多次卷积来从分提取图像**特征**与**风格**。浅层表示**特征，感受野更小，更注重细节**；深层表示**风格，感受野更大，更注重整体**。

#### 池化：

VGG16使用max-pool来**缩小特征图尺寸，减小参数，扩大感受野，增强平移不变性，提取显著特征**。

#### **激活函数：**

引入**非线性**，增强模型拟合能力，卷积、全连接本质上都是**线性变换**，线性变换的叠加并不能增强拟合能力。

#### **全连接：**

通过矩阵乘法来**缩小特征图尺寸**，从整体上来提取图像**风格**。

#### loss：

**gram矩阵：**

VGG16的特征图是 `(C, H, W)`，C 是通道数，H是高度，W是宽度。

```py
c = x.shape[1]
    f = x.reshape(c, -1)
    return f @ f.t()
```

把 `(C, H, W)` 拉平成 `(C, N)`(，即把C个高H宽W的二维向量reshape成C行长H × W的一维向量，而其中每个元素代表一个特征。

![](https://pic2.zhimg.com/v2-c31c8591818dcb5ea833b9a1b1253f29_1440w.jpg)

我们将矩阵`(C, N)`转置并与自身进行内积，于是G中每个元素表示多个特征的组合值，因为是不同通道两两相计算使得不同特征得到了组合。

**风格损失：**

![](https://pic2.zhimg.com/v2-cbd6c47518ccee378375b803af7de985_1440w.jpg)

    channels = 3

**内容损失：**

```py
torch.sum((base - combination) ** 2)
```

将内容图与生成图在VGG中的特征图，**逐元素平方差求和**即可。

**全变分损失：**

```py
h, w = x.shape[2], x.shape[3]
a = (x[:, :, : h - 1, : w - 1] - x[:, :, 1:, : w - 1]) ** 2
b = (x[:, :, : h - 1, : w - 1] - x[:, :, : h - 1, 1:]) ** 2
return torch.sum((a + b) ** 1.25)
```

将相邻像素在各方向平方差求和。它可以抑制噪点、让画面更平滑。
